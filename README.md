# MEW Shift

تطبيق ويب لموظفي الشفتات في محطة الشعيبة (وزارة الكهرباء والماء): جدول المجموعات، البصمات ووقت الخروج، بصمة التواجد، الأذونات والتأخيرات، والإجازات.

الرابط: https://work.ihussain.net

## الملفات

```
index.html            ← صفحة التطبيق
css/app.css           ← التصميم (نهاري وليلي)
js/rules.js           ← قواعد الدوام والعطل الرسمية (عدّل هنا)
js/i18n.js            ← النصوص بالعربية والإنجليزية
js/app.js             ← الواجهة والحسابات
sw.js                 ← العمل بدون إنترنت
manifest.webmanifest  ← الإضافة للشاشة الرئيسية
```

## الخصوصية

بيانات كل موظف تُحفظ في متصفح جهازه فقط (localStorage) ولا تُرسل لأي خادم.

## النشر

تلقائي عبر GitHub Pages عند كل تحديث على `main`.
